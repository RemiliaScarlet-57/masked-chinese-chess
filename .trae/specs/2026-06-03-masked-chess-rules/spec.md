# 象棋揭棋最优解计算器 - 项目规格说明

## 1. 项目概述

本项目是一个基于 Web 的象棋揭棋游戏和最优解计算器。揭棋是中国象棋的变体，所有非将帅棋子初始为暗棋状态，需要移动后才能揭开揭示真实兵种。

## 2. 核心规则

### 2.1 明子走法（与标准象棋一致）

| 棋子类型 | 走法规则 |
|---------|---------|
| **车** | 直线任意格，不能穿越棋子；空位=移动，敌方棋子=吃掉 |
| **马** | 日字跳跃，需检查蹩马脚（正交邻格是否有子）；可落空位或敌方棋子 |
| **炮** | 空移=车式直线不穿；吃=同线恰有1个炮架（任意棋子）+落点为敌方棋子 |
| **相/象** | 田字跳跃，塞象眼（中心点有子则不能走），不能过河（红方行0-4，黑方行5-9） |
| **仕/士** | 九宫内对角线一步 |
| **帅/将** | 九宫内正交一步；禁止飞将（双方将帅不能在同一线直接对面） |
| **兵/卒** | 未过河前只前进1；过河后可前进/左/右各1；不能后退 |

### 2.2 暗子走法规则

**核心机制**：每个暗子内部有一个 `hiddenType`（隐藏类型），在初始化时随机分配（不能是将帅）。

| 暗子内部类型 | 合法落点（移动前仍盖着） |
|-------------|------------------------|
| **暗车** | 沿横/竖直线走任意格，不能穿越任何棋子；空位=可走；敌方棋子=可吃；己方棋子=不可落 |
| **暗马** | 日字跳跃，蹩马腿看正交邻格是否有子；落点空或敌方棋子 |
| **暗炮** | 空移=直线不穿；吃=同线恰1个炮架（可以是暗子或明子，颜色不论）+落点为敌方棋子 |
| **暗相/象** | 田字跳跃，塞象眼，不能过河（暗相也不能过河） |
| **暗仕/士** | 九宫内对角线一步 |
| **暗兵** | 按当前"过河状态"判断：未过河的暗兵只能前1；已过河的暗兵可前/左/右1 |

**暗子走完后的处理**：
- 自动翻开，揭示 `hiddenType` 作为真实类型
- 后续走法按揭示后的兵种规则执行

### 2.3 胜负判定

- 吃掉对方的将帅即为胜利
- 双方都无法移动时为和棋

## 4. 数据结构

### 4.1 棋子类型

```typescript
type PieceType = 'king' | 'guard' | 'elephant' | 'horse' | 'chariot' | 'cannon' | 'soldier';
type PieceColor = 'red' | 'black';

interface Piece {
  id: string;
  type: PieceType;        // 表面类型（明子）或揭晓后的真实类型
  color: PieceColor;
  isRevealed: boolean;     // 是否已翻开
  position: Position;
  hiddenType?: PieceType; // 暗子内部的真实类型（初始化时分配）
}

interface Position {
  row: number;  // 0-9 (10行)
  col: number;  // 0-8 (9列)
}
```

### 4.2 游戏状态

```typescript
interface GameState {
  pieces: Piece[];
  currentPlayer: PieceColor;
  history: Move[];
  status: 'playing' | 'red_win' | 'black_win' | 'draw';
  selectedPieceId: string | null;
  darkPieceProbabilities: DarkPieceProbability[];
  remainingPieces: Map<PieceColor, Map<PieceType, number>>;
}

interface Move {
  pieceId: string;
  from: Position;
  to: Position;
  capturedPieceId?: string;
  isReveal: boolean;
  isCheck: boolean;
}
```

### 5.2 棋盘结构

- **尺寸**：10行 × 9列 = 90个交叉点
- **棋子放置**：放在交叉点上，不是格子中心
- **楚河汉界**：第5-6行之间
- **九宫格**：双方底线中央3×3区域，含对角线
- **马的位置标记**：双方九宫角外的位置

## 6. 游戏模式

| 模式 | 描述 |
|------|------|
| **双人对战** | 红方和黑方交替由人类操作 |
| **人机对战** | 红方=人类，黑方=AI（自动响应） |
| **AI对战** | 红方和黑方都由AI控制，自动进行 |

## 7. 棋子移动规则矩阵

### 7.1 明子移动（按类型）

| 类型 | 方向约束 | 跳跃能力 | 特殊规则 |
|------|---------|---------|---------|
| 车 | 横+竖 | 不能穿越 | 无 |
| 马 | 日字 | 可跳跃 | 蹩马脚检查 |
| 炮 | 横+竖 | 不能穿越 | 吃需炮架 |
| 相 | 田字 | 可跳跃 | 塞象眼、不过河 |
| 仕 | 九宫对角 | 不能跳跃 | 无 |
| 帅 | 九宫正交 | 不能跳跃 | 禁止飞将 |
| 兵 | 前进（过河后可横） | 不能跳跃 | 不能后退 |

### 7.2 暗子移动（按 hiddenType）

| hiddenType | 与明子规则的差异 |
|-----------|----------------|
| 暗车 | 完全一致 |
| 暗马 | 完全一致 |
| 暗炮 | 完全一致 |
| 暗相/象 | 完全一致（不能过河） |
| 暗仕/士 | 完全一致（九宫限制） |
| 暗兵 | 按当前位置判断是否过河 |

## 8. 状态历史

### 8.1 游戏流程

1. **初始化**：生成棋盘，分配 `hiddenType` 给所有暗子（将帅除外）
2. **红方先行**：选择己方棋子，显示合法移动
3. **执行移动**：移动棋子，如果是暗子则自动翻开
4. **切换玩家**：轮到对方走棋
5. **重复步骤2-4**：直到游戏结束
6. **判定胜负**：将帅被吃则游戏结束

### 8.2 状态消息格式

| 操作类型 | 消息格式 |
|---------|---------|
| 暗子移动吃子 | `红方暗子移动到九九，翻开为马，吃掉对方棋子！` |
| 暗子移动翻开 | `红方暗子移动到八二，翻开为车` |
| 明子移动 | `红方马从九二走到九三` |
| 明子吃子 | `红方车从八二走到八三，吃掉对方棋子` |
